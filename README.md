Drop the SCLOCKS.ACC file in to the root directory of the Atari ST boot drive and reboot. 

Set the clock from your control panel in the Desk dropdown menu.

From the Desk dropdown menu, you can select Simple Clock and make a few changes. You can cycle between no clock, hour/minutes, and hour/minutes/seconds. You can also turn on the hourly beep. The beep function has to be turned on after every reboot. When turned on, there will be a small dot to the right of the time.

If you are using a RTC (real time clock), like an ACSI2STM with battery, it will hold the time and stay accurate between power cycles and reboots. No need for other utilities to fetch the time assuming you are using GemDrive mode. Ultra Satans might be different if they are strict ACSI compliant and might require the time set/fetch utilities.

*** NOTE: some versions of TOS are not Y2K compliant, I use Rainbow 1.04 which isn't, and you will need a program in your AUTO folder to fix the date problem. I use DATEFIX.PRG and it works great. However, this isn't really an issue with Simple Clock because it doesn't have a date function. :)
